# 筆順ビューア

漢字を入力すると、1画ずつアニメーションで筆順を表示します。日本の字形・筆順のオープンデータ KanjiVG を使います。

## 準備（1回だけ）

このフォルダで実行します。

```bash
git clone --depth 1 https://github.com/KanjiVG/kanjivg.git
npx serve .
```

`kanjivg/kanji/` の中に、漢字ごとのSVGが約11,000字ぶん入ります。以後はネット接続不要です。

以前入れた `hanzi-writer` 系は使いません。消しておく場合は `rm -rf node_modules package.json package-lock.json`。

## 開き方

`npx serve .` を実行すると3000番ポートが立ちます。Codespacesの場合は「ポート」タブに出る転送先URLを開いてください。`index.html` を直接ダブルクリックすると読み込みに失敗します。

## 使い方

- 漢字を入れて「表示する」。熟語なら1文字ずつタブで切り替わります
- **再生** … 1画目から通しでアニメーション。朱色が今書いている画
- **1画進む** … 1画ずつ止めて確認
- **なぞる** … マスの上を指やマウスでなぞって練習
- **速さ** … ゆっくり／ふつう

## 仕組み

KanjiVGのSVGから `<path>` を書き順どおりに取り出し、`stroke-dasharray` と `stroke-dashoffset` で線を描き進めています。ファイル名は文字コードの16進5桁で、たとえば「妻」（U+59BB）は `kanjivg/kanji/059bb.svg` です。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `styles.css` | 配色・レイアウト |
| `app.js` | SVGの読み込みとアニメーション制御 |
| `kanjivg/kanji/` | 筆順データ（git cloneで取得） |

## 手を入れるなら

- 書いた線とお手本を比べて、順番の誤りを指摘する判定機能
- 苦手な漢字をリスト化して繰り返し出題する練習モード
- 画数・部首・読みの表示（別途データが必要）
